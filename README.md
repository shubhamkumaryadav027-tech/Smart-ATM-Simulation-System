# Smart ATM Simulation System

A console-based ATM simulation built using Core Java.

## Features
- PIN verification before access
- Transaction tracking
- Cash withdrawal limits
- Deposit and balance check

## Tech Used
- Core Java (OOP concepts)

## How to Run
1. Clone the repo:
   `git clone https://github.com/shubhamkumaryadav027-tech/Smart-ATM-Simulation-System.git`
2. Compile: `javac ATMMachine.java`
3. Run: `java ATMMachine`
